경력

인슈어테크 스타트업

풀스택 개발자 · 2025.09 ~ 재직 중

설계사용 앱, 고객용 앱, 관리자 콘솔이 하나의 모노레포로 구성된 보험 플랫폼을 개발·운영하고 있습니다.

Frontend
Angular(Signals, Standalone) 화면 개발, 검색·필터 상태 보존 등 UX 개선
Backend
NestJS + TypeORM(MySQL) API, 외부 보험사 API 연동, 권한 가드 설계
Mobile
Capacitor 기반 iOS/Android 하이브리드 앱 운영, WebView·네이티브 플러그인 이슈 해결
Data · AI
Firestore 트랜잭션, GCP Cloud Run, BigQuery·Looker Studio, Vertex AI(Gemini) 프롬프트 설계

기억에 남는 문제 해결

  • 카카오페이 결제 후 앱 복귀 시 연결 오류

    결제 앱에서 돌아올 때(포그라운드 전환) 결제 결과 확인 흐름이 끊기는 문제를 분석하고, 복귀 시점에 결제 상태를 안정적으로 이어받도록 개선했습니다.

    결제 · Capacitor

  • 환불 처리 정합성

    두 가지 결제 수단이 섞인 환경에서 환불 도중 데이터가 어긋나지 않도록 트랜잭션으로 묶어 한 번에 처리되게 했습니다.

    Firestore

  • 회원 탈퇴 데이터 정리

    MySQL, Firestore, Firebase Auth에 흩어진 회원 데이터를 삭제 순서와 실패 상황까지 고려해 정리하는 흐름을 만들었습니다.

    NestJS · Firebase

  • 하이브리드 앱 플랫폼 이슈

    iOS 카카오톡 공유와 WKAppBoundDomains 충돌, Android WebView 다운로드 불가, 결제 플러그인 빌드 오류를 각각 원인부터 찾아 해결했습니다.

    iOS · Android

  • 늦게 도착한 응답이 화면을 덮어쓰는 문제

    연속 요청 시 이전 응답이 나중에 도착해 화면이 꼬이던 문제를 RxJS 스트림 구조로 리팩토링해 해결했습니다.

    Angular · RxJS

  • 제휴사 API 사용량 대시보드

    로그를 구조화해 BigQuery로 연결하고, 제휴사별 사용량을 Looker Studio에서 바로 확인할 수 있게 구성했습니다.

    GCP · BigQuery
